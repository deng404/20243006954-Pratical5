# Practical 5 - Android Intent Implementation

## Note
Due to environment limitations, this repository contains the source code files. 
The `res/drawable` folder requires physical image files (beijing.jpg, tianjin.jpg, etc.) which cannot be uploaded via the GitHub web editor directly. 

## Features Implemented
1. ListView displaying Chinese municipalities.
2. Explicit Intent to pass selected city to `DetailActivity`.
3. Implicit Intent for sharing city information.
